- Zgłoszenie **tylko przez formularz na stronie GitHuba**, wypełnione przez człowieka. Nie przez `gh` w terminalu i nie jako PR — za to grozi czasowa blokada w repozytorium listy.
- Repozytorium musi mieć **co najmniej 14 dni od pierwszego commita** na głównej gałęzi i ślady dalszej pracy (albo 100 gwiazdek). Nasz pierwszy commit: 17.11.2026, 15:51. Czternaście dni mija **01.12.2026 o 15:51** — wysyłamy najwcześniej 01.12 po południu, bezpieczniej 02.12. Zgłoszenie wcześniej zostanie zamknięte automatycznie.
- Jedno zgłoszenie naraz.
- Licencję sprawdza automat — mamy plik `LICENSE` (MIT), GitHub go rozpoznaje.
- Opis ma opisywać, a nie reklamować: bez zwracania się do czytelnika, bez emoji, jedna linia, 10–500 znaków.
- Autor listy pisze wprost, że wybiera ostrożnie i nie każde zgłoszenie przyjmuje; brak odpowiedzi też jest możliwy.
